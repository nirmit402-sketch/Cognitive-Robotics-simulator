Cognitive Robotics Practical Simulation App

This single HTML app converts the lecture ideas into hands-on mini labs. It covers cognition, brain-body-environment interaction, Bayesian reasoning, anticipation, reinforcement learning, sensorimotor coordination, affordances, tool use and cognitive architectures.

Why this app?

The lectures describe cognitive robots as autonomous systems that perceive, act, adapt, learn and anticipate. Here those words become visible: you can change noise, delays, learning rates, reward structure, body growth and object properties, then watch the robot behave differently.

What to demonstrate in class

  • Reaction versus anticipation in catching.
  • Bayesian inference from uncertain evidence.
  • How Q-learning gradually improves action selection.
  • How affordances emerge through exploration.
  • How a cognitive architecture connects modules into flexible behaviour.

Suggested teaching flow

Start with the Cognitive Loop lab, then use Bayesian Network for uncertainty, Anticipation for prediction, Reinforcement Learning for trial-and-error, Sensorimotor Reaching for embodied coordination, Affordance Learning for object-action-effect relations, Tool Use for planning, and Cognitive Architecture to connect everything.

How the reinforcement-learning simulation works

This grid world represents a robot learning a navigation policy through trial and error. The robot starts at the bottom-left, must reach the GOAL, and should avoid the HAZARD cells. There is deliberately no pre-written route: the policy is built from reward feedback.

1. Choose an action

At each state the robot chooses Up, Right, Down or Left. With probability ε it explores a random action; otherwise it selects the action with the highest current Q-value.

2. Receive feedback

Reaching the goal gives +10, entering a hazard gives −8, and every ordinary move gives −0.1. This makes shorter, safer routes more useful.

3. Update Q-values

The simulation applies Q-learning: Q(s,a) is moved toward the received reward plus the discounted value of the best next action. α controls how strongly new experience changes the estimate.

4. Look ahead

γ controls how much future rewards matter. A high γ encourages the robot to value actions that lead toward a useful future state rather than only immediate reward.

5. Learn a policy

The arrow in each ordinary cell shows the currently best-valued action. Early arrows can be uninformative because all Q-values start at zero; after training, useful directions emerge.

6. What the goal demonstrates

The learning goal is not memorising a fixed path. It is demonstrating how repeated interaction and reward can produce an improving action-selection policy.

What to observe: train several times, then compare the arrows and Q-values with the untrained grid. Increase ε to make behaviour more exploratory, increase α to make new feedback change learning faster, and change γ to alter the importance of future rewards.

An affordance is not only a property of an object. It depends on the relation between object, action, robot body and environment.

Understanding the affordance-learning simulator

What the simulator represents: This simulator models how a robot can discover affordances by interacting with different objects. An affordance is the action possibility that emerges from the relationship between the object, the chosen action, the robot's capabilities and the environment. Instead of assuming the correct outcome is known in advance, the robot builds experience from repeated trials.

How it works

Select an object and an action, such as pushing a ball or grasping a cup. Each trial samples an outcome from the simulator's object-action model. The result is added to the robot's experience table, and the displayed effect probabilities are recalculated from the accumulated trials.

What it represents

The table is a simplified learned model of the relationship object → action → effect. Different objects respond differently to the same action, so the robot must learn which interactions are useful rather than treating every object in the same way.

Key outcome to observe

Watch the effect probabilities become more informative as the number of trials increases. The important outcome is convergence toward a useful prediction of what an action will do. Use Auto explore to see how experience gradually turns uncertain interaction into a more reliable affordance model.

Key observation: Compare the same action on different objects. The learned probabilities should differ, demonstrating that an affordance is relational rather than simply a fixed property stored on the object.

Understanding the tool-use planning simulator

What the simulator represents: This simulator demonstrates how a robot can use learned or predicted affordances to choose actions and tools that are likely to produce a desired effect. The robot starts with a task goal, considers the available tool, and selects a simplified action plan based on the predicted usefulness of the available object-tool-action combination.

How it works

Choose a goal such as bringing an object closer, moving it right, or lifting it. Then choose a long stick, hook, or no tool. When Plan action is pressed, the planner evaluates the available combination and returns an action, a predicted success percentage and a short reason. The canvas then animates the planned effect.

What it represents

This is a simplified model of planning from affordances: the robot is not only asking “what action can I perform?” but “which action, with which tool, is likely to create the effect I need?” Tool use therefore extends the robot's reachable actions beyond direct body interaction.

Key outcome to observe

Change only the available tool while keeping the goal the same. Observe that the selected action and predicted success can change. The key outcome is goal-directed action selection based on predicted effects, rather than choosing an action randomly or using a single fixed behaviour.

Key observation: A tool is useful because it changes the set of achievable effects. Compare “No tool”, “Long stick” and “Hook tool” for the same goal and examine how the plan changes.

A cognitive architecture acts as glue: it links perception, memory, language, planning and motor execution into one behaviour.

Understanding the cognitive-architecture simulator

What the simulator represents: This simulator shows how multiple cognitive modules can be connected into one robot behaviour. A high-level human instruction is progressively transformed into goals and memory, visual object understanding, affordance perception, action planning and finally low-level action execution. It is a teaching model of the flow between cognition, perception and behaviour rather than a complete robotic operating system.

How it works

Select a command and an architecture style, then run the flow. The modules activate sequentially from high level to mid level to low level. At each step, the simulator displays the corresponding interpretation—for example, detecting an object, identifying its affordance, planning the action and executing the movement.

What it represents

The architecture acts as the coordination layer between language, perception, memory, affordance reasoning, planning and motor control. The three styles provide simplified conceptual views: cognitivist emphasises a fixed symbolic flow, emergent emphasises adaptive self-organisation, and hybrid combines symbolic and adaptive modules.

Key outcome to observe

Watch the command move through the complete chain instead of jumping directly from language to motor output. The key outcome is functional integration of modules: a high-level goal becomes an executable sequence of lower-level actions through intermediate representations and decisions.

Key observation: Compare the three architecture styles using the same command. Focus on which parts of the process are represented as explicit reasoning, adaptive interaction, or a combination of both.
